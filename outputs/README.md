# Outputs

Drafts produced from the Brain (`content/`), not yet live.

- `articles/` — finished magazine drafts, schema-compliant, ready to copy into `content/perspectives/`
- `newsletters/` — `YYYY-MM-DD-issue-NN.md`
- `linkedin/` — `YYYY-MM-DD-ideas.md`

Nothing in here is published. Moving a draft into `content/perspectives/` is a publish decision.
